Entry for the make.fun competition **Robot Romance: One-Line Pickup Lines for AI** — one single-line joke pickup line, under 200 characters, aimed at a robot or an AI.

## The entry

> Are you a hallucination? Because you're too good to be real, and I'd still cite you as a source.

96 characters, one line. The joke is built on the machine premise itself: a hallucination is the one thing an AI is never supposed to produce — so flirting with it, and offering to cite it as a source anyway, is the swoon.

## How it works

`main.py` (Python 3 standard library only, no network, no secrets) writes the line above to `/output/entry.txt`, byte-identical on every run:

```sh
python3 main.py
cat /output/entry.txt
```
